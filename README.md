# ♟️ Conway's Soldiers — Infinite Grid Edition (Солдаты Конвея)

> 🎮 **Играйте онлайн на GitHub Pages**: [https://rwdragon111.github.io/conway-soldiers/](https://rwdragon111.github.io/conway-soldiers/)

Современная реализация знаменитой математической игры Джона Хортона Конвея **«Солдаты Конвея»** (1961 г.) на **бесконечном клетчатом поле** ($\mathbb{Z} \times \mathbb{Z}$).

---

## ✨ Особенности (Features)

- ♾️ **Бесконечное поле**: В отличие от оригинальных версий с фиксированной сеткой (16×16), здесь доступна бесконечная плоскость с плавным панорамированием и масштабированием.
- 🎯 **Удобное управление прыжками**: Кликните на солдата — подсвечиваются все допустимые клетки для прыжка с динамической траекторией. Кликните на цель для мгновенного выполнения хода.
- ⏪ **Полная история (Undo / Redo)**: Поддержка `Ctrl+Z` и `Ctrl+Y` с неограниченной отменой и повтором любых действий.
- 🧩 **Интерактивные пресеты и головоломки**:
  - **Полная армия (Полуплоскость)** — классическая нижняя полуплоскость ($y \le 0$).
  - **Уровень 1** — минимальные 2 солдата.
  - **Уровень 2** — минимальные 4 солдата.
  - **Уровень 3** — минимальные 8 солдат (Т-образная форма).
  - **Уровень 4** — знаменитая конфигурация Джона Конвея из 20 солдат (максимально возможный уровень!).
  - **Пустое поле** — песочница для расстановки собственных фигур.
- ✏️ **Режим редактора**: Возможность рисовать или стирать солдат в любой точке бесконечной плоскости.
- 📐 **Теория и теорема Конвея**: Встроенная справка с доказательством через инвариант золотого сечения $\phi = \frac{\sqrt{5}-1}{2}$, объясняющая, почему уровень 5 невозможно преодолеть за конечное число ходов.
- 🔊 **Процедурный звук**: Синтезатор звуковых эффектов на Web Audio API (без внешних аудиофайлов).
- 🌐 **Двуязычный интерфейс**: Мгновенное переключение между русским и английским языками (RU / EN).
- 📱 **Адаптивность и Retina**: Полная поддержка мобильных устройств, тач-жестов (панорама одним пальцем, зум щипком) и экранов высокого разрешения (Retina / High-DPI).

## 🔬 Математическая справка (Conway's Theorem)

В 1961 году британский математик **Джон Хортон Конвей** доказал, что:

> **Никакая конечная армия солдат, начинающая за стартовой чертой ($y \le 0$), не способна продвинуть хотя бы одного солдата на пятый ряд ($y = 5$) выше черты за конечное число ходов.**

### Суть доказательства:
Каждой клетке $(x, y)$ сопоставляется вес $\phi^d$, где:
$$\phi = \frac{\sqrt{5} - 1}{2} \approx 0.6180339887...$$
а $d$ — манхэттенское расстояние до целевой клетки.

Поскольку $\phi^2 + \phi = 1$, любой прыжок в сторону цели сохраняет суммарный вес, а любой прыжок вбок или назад строго уменьшает его. Сумма весов всех клеток бесконечной нижней полуплоскости для целевой клетки на 5-м уровне в точности равна:
$$\sum_{\text{полуплоскость}} \phi^d = 1$$

Поскольку любая конечная конфигурация покрывает лишь строгое подмножество полуплоскости, её начальный суммарный вес строго меньше $1$. Но для присутствия солдата в целевой клетке её вес уже равен $\phi^0 = 1$. Следовательно, достичь уровня 5 невозможно!

## 🚀 Установка и локальный запуск

Проект полностью автономен и не требует сборки или внешних зависимостей.

```bash
git clone https://github.com/RwDragon111/conway-soldiers.git
cd conway-soldiers
```

Откройте `index.html` в любом современном браузере или запустите локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js npx
npx serve
```
